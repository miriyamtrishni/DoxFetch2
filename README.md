# DoxFetch

- The purpose of the DoxFetch App is to make it easier for users to request replacement NICs for lost NICs, renew passports, and obtain copies of certificates. By entering their NIC number, mobile number, and email address, users can register on the app. Users can simply apply for these documents, make payments, and follow the status of their requests in real time once they have registered. Because the app lets users pick up their documents whenever they're ready, it saves them from having to stand in line at government offices. 
---

## Target Audience

- Those are who looking for an easy and quick way to apply for and monitor the status of their document requests; citizens in need of certificate copies; those renewing their passports; and those replacing their NIC. 
---
## Issue it Resolves

- The traditional document application process's lengthy wait times and inefficiencies.
- Absence of openness and visibility regarding the standing of document requests.
- The inconvenience of physically collecting documents from government departments.

## How to Run the Project

1. **Clone the Repository:**  
   ```sh
   git clone <repository-url>
   cd <project-directory>
   ```

2. **Open in Android Studio:**  
   - Open Android Studio
   - Click on "Open an Existing Project"
   - Select the cloned project directory

3. **Build and Run the App:**  
   - Connect an Android device or use an emulator
   - Click on "Run" (▶️) in Android Studio

4. **Install Dependencies (if required):**  
   ```sh
   ./gradlew build
   ```

5. **Troubleshooting:**  
   - Ensure Android SDK is installed and configured
   - Check for any missing dependencies and sync Gradle
```
